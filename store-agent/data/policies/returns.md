# Returns and refunds

You can return an item within 30 days of delivery. Worn or used items can't be returned: clothes and shoes must be unworn, with the original tags.
Start a return in the chat or in your account. Our team checks every request and confirms it within 2 business days.
Refunds go back to the original payment method within 5 to 7 days after we receive the item.
Return shipping is free for orders over $50. For smaller orders, the return label costs $5.
Sale items marked "final sale" cannot be returned.
